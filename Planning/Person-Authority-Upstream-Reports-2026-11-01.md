# Reports for HistoryAtState/people: three drafts, 2026-11-01

**What this is.** Drafts of issues for [HistoryAtState/people](https://github.com/HistoryAtState/people), the CC0 registry the person authority is built from. #1767's two lanes and the A4c overlay review found them and left them for upstream (`Planning/Person-Authority-Overlay-Review-2026-10-17.md` §6.3, `Planning/Person-Authority-Lane-Design-2026-10-28.md` §4.5 and §4.6, and #1815's body). **None is filed.** Filing an issue on another organisation's repository is outward-facing, so each waits for the owner's word; the text under each heading is ready to paste as the issue's body, under the title given.

**What was read.** The registry at `63b537ad`, still `master` on 2026-11-01 (`git ls-remote`), all 16,312 records, by preferred name and every source-url. Each anchor's entry in its own volume's persons list, from `HistoryAtState/frus` at `6170e4b32`. Each record link below is pinned to `63b537ad`; each anchor link is the anchor's page on history.state.gov. The repository had no issues filed on 2026-11-01, so there is no house format to follow.

**What FRUS Explorer does meanwhile.** The registry wins every disagreement by design, so none of these can be corrected in the bundle except where the overlay or a correction places an anchor the registry does not answer:
- The merges (draft 1) reach the app as filed: 113000's ten Senator anchors, 114659's nine Defense Mobilization anchors and one Representative's and 104298's one sit in those records' rollups.
- The duplicates (draft 2) are each two people in the People list. An uncovered entry that fits both joins the one its exact name fits, or neither (#1658's tie rule, rollup v13).
- The Wright anchors (draft 3) are placed by the corrections file's `assigned` list. When upstream adds one to 114825, the generator refuses to write ("the registry now gives … to 114825, as its assignment does: remove the assignment"). So a fix upstream shows up as a red run here, and the assignment is then deleted.

## When one is filed or fixed

- Record the issue's link here.
- When upstream changes a record, regenerate the bundle against the new registry. The corrections file's refusals name whatever no longer fits.
- A record upstream adds for Adlai Stevenson III, Charles Edward Wilson, Charlie Wilson or Hamilton Fish IV makes no correction refuse. The corrections hold these men's overlay anchors apart from the merged records, and those anchors are in the bundle's `apart` list today. An anchor the registry then answers leaves the list, and joins the new record.
- **The registry wins**, so a fixed merge moves anchors on its own. A regeneration that moves the crosswalk takes a person rollup version bump in the same commit.
