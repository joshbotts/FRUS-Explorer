## 3. Accessibility gaps, ranked by severity

**Baseline counts** (grep): `accessibilityLabel` 194, `accessibilityHint` 22, `accessibilityValue` 4, `accessibilityElement` 19, traits/actions/rotor 38, `.help` 142, `Image(systemName:)` 241, **`.font(.system(size:))` 344**, `dynamicTypeSize`/`ScaledMetric` **1**, `@FocusState`/`focusable` **2**, `differentiateWithoutColor` **0**, contrast/transparency env **0**. Reduce-motion: handled in both graph views + word cloud (good).

### Severity 1 — blocking for some users
- **A1. Dynamic Type is effectively unsupported on key iOS surfaces.** 344 fixed-point fonts; only one scaled metric app-wide. Worst iOS-visible offenders: `Onboarding/OnboardingView.swift` (5), `App/IndexingBannerView.swift` (6), `App/IndexingQueueBannerView.swift` (8), `DocumentView/DocumentView.swift` (4), plus 22 fixed `.frame(height:)` sites. Mitigation (PR-sized per file): replace `.system(size:)` with text styles or `@ScaledMetric`; audit the 22 fixed heights with AX5 sizes. (The 145 in `Settings/FRUSSettingsView.swift` and 72 in `App/SupportingViews.swift` are macOS-only — lower priority but not exempt on macOS 14+ text scaling.)
- **A2. Rich-text prose editor ignores Dynamic Type on iOS.** `UITextView` gets a one-shot `preferredFont(forTextStyle: .callout)` and never sets `adjustsFontForContentSizeCategory = true` (`Collections/CollectionRichTextEditor.swift:219-227`); RTF round-trips concrete fonts, so even relaunching doesn't rescale existing prose. Mitigation: set `adjustsFontForContentSizeCategory`, and map stored fonts through `UIFontMetrics` at display time. Also: the fixed-height iOS highlight-picker detent `.presentationDetents([.height(180)])` clips at large type (`DocumentView/DocumentView.swift:1825`).
- **A3. macOS highlight color picker is a color-only, label-free control.** Plain circle buttons with only `.help(color.rawValue.capitalized)` — unlocalized, and no `accessibilityLabel`, so VoiceOver reads nothing meaningful (`App/SupportingViews.swift:497-514`). iOS variant has labels but also unlocalized `color.rawValue.capitalized` (`DocumentView/DocumentView.swift:1808`). Mitigation: use `DocumentHighlight.Color.displayName` (`Models/DocumentHighlight.swift:185`) for both label and help, add a shape/initial glyph for `differentiateWithoutColor`.

### Severity 2 — major friction
- **A4. VoiceOver cannot reorder the collection outline.** Reorder is `onMove` drag-handles behind `EditButton` on iOS (`Collections/CollectionEditorView.swift:992,1070`) and raw drag on macOS (`MacCollectionManagerView.swift:718`); context menus offer indent/outdent/delete but no Move Up/Down (`Collections/CollectionEntryRows.swift:189-232`). Mitigation: add `.accessibilityAction`s (and context-menu items) for Move Up / Move Down on every row type — one PR, shared helper next to `structuralDeleteButton`.
- **A5. Selection state conveyed only by SF-symbol swap** (checkmark.circle vs circle) with no `.isSelected` trait or `accessibilityValue`: `Collections/CollectionAddDocumentsSheet.swift:1349`, `Settings/FRUSSettingsView.swift:555,1950,2322`.
