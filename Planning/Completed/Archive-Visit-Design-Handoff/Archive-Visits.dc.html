Chrome mirrors stock iOS/iPadOS/macOS SwiftUI — implement with native components (List inset-grouped, .bordered/.controlSize(.small) menu chips, ContentUnavailableView, alerts with TextField), not these pixels. ● measured — reuse as stated · ○ illustrative — computed at render time, never hard-coded. Plain labels on screen; precise definitions live in each surface's ⓘ popover (FeatureInfoButton, drawn open once in 1b). The honesty rule is inherited whole: a partial figure states both numbers; incomplete coverage renders orange, complete renders secondary.
THE GRAIN
The research target, not the document. One archival unit under one claim — drawn from or pointed at. Targets are a state overlay: a row is stored only once it has a tier, a note, or an exclusion; everything else derives at render time.
THREE DELIVERABLES
(a) repository visit-planning links — built, 11 facilities ● · (b) repository-filtered, tier-grouped target list with consultation metadata · (c) per-repository inquiry email drafts. Four of the packet's seven chapters are gone.
VOCABULARY
Archive Visit (never "collection" — that word is already two things) · Plan a Visit / Add to Archive Visit… · research target · priority tier (unlabeled reads "Priority 1") · Unprioritized, implicit and always last.
The app's job is FRUS, not NARA: it presents FRUS-derived data in the form most useful for planning and for consulting an archivist, and points at repository guidance rather than reproducing it. Persistent, CloudKit-synced, seedable from anywhere a researcher meets archival provenance.

About research targets
A target is one archival unit under one claim. Drawn from: the document was published from this file — its own source note. Pointed at: the document's footnotes cite this, unprinted. One document can seed several targets, each prioritized on its own; the two counts are never added because they answer different questions. A row is stored only once you give it a tier, a note, or an exclusion — the rest derives from the seeds each time, so it stays right as volumes index. Corpus-wide, ~21 source-note groups arise per 30 documents ● (25 pre-1950, 14 post-1950); footnote references to unprinted material exist on ≲6% of documents ●.

ⓘ Claim definitions, target population, and why counts never sum — in the info popover above.
Sections by repository; headers carry that facility's (a) links verbatim from RepositoryFactTable (College Park's three ●, each library's D16 pair ●; a link renders only with a verifiedDate). Within a section, group by tier, Unprioritized last. Filter chips use the Wave-B ViewThatFits one-row/stacked grammar from ArchivalAnalyticsView. Records line composes through TripPacketModel.recordsLine — one formatter, never two. Claim counts NEVER summed. Restriction is a line, not a badge: worst covered status + the series it belongs to + unmeasured claimant count (● 123 divided lots shipped, one claimed by up to 13 series), routed into (c). Expanded rows quote the verbatim reference context — source note for drawn-from, footnote citation with anchor for pointed-at, Ibid. rows disclosing inheritance; claim groups visibly distinct; elision uses the shipped 12/8/20 truncation grammar with exact counts. In-app the document link navigates; in export it is the short citation + history.state.gov URL. States not drawn: no seeds → ContentUnavailableView; seeds but no derived targets → say which half is missing; fewer indexed volumes → the orange summary line above.

Each document contributes through two switches: its own source note (drawn from) and its footnotes' citations to unprinted material (pointed at). References beyond FRUS exist on about 6% of documents ● — where a half is absent, the control is a caption, never a dead toggle.
The two contribution controls reuse CollectionEntryInspector's shipped Default/On/Off overridePicker grammar (menu picker; "Default" states the effective value). Sparsity is a design constraint (≲6% ●): absent references → ● "No unprinted references in this document's footnotes"; absent source note (pre-1906 by design) → ● "This document carries no source note". Both halves off → the "contributes nothing" warning chip.
