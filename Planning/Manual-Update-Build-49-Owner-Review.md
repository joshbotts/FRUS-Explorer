# The build-49 manual update: what the owner's review needs

Both user manuals were brought up to date by Claude on 2026-10-07 and carry an **AI Generated** notice directly under their titles. The owner has not reviewed them. **The notice stays until the owner has, and not before 2026-10-21**: a lane that edits a manual leaves it in place.

This file is the worklist for that review. It does not repeat the manuals' text; read the pull request's diff for that.

## What was done

1. **Audit (2026-10-02, at `252298f8`).** Every statement in `Docs/macOS-User-Manual.md` and `Docs/iOS-User-Manual.md` was read against the code, together with the 137 proposals lanes had left in `Planning/Manual-Revisions-Pending.md`. Each proposed change was checked by a second reader. Result: 469 change records, 191 Mac and 278 iOS.
2. **Second review (2026-10-07, at `f384d2d5`).** Each record was read again by a reviewer told to refute it, against the code as it then stood, after the web edition's kit moves and #1578. 427 were confirmed, 41 were amended and 9 were added; every objection was itself re-checked twice before its text was taken. Most amendments narrow a sentence that is true on one device, width or condition and was stated more broadly.
3. **Twins.** Where a correction to one manual had a twin sentence in the other, or a sibling elsewhere in the same manual, the same correction was carried across where the code behind it is shared by both platforms, or after reading that platform's own: 21 more edits, 15 Mac and 6 iOS. Seven of them were proposed by a reader who cited the code line by line; the rest were made by hand.
4. **Applied by script.** 205 records to the Mac manual and 285 to the iOS manual. The script requires each record's old text to occur exactly once and no two to overlap, and checks every section pointer, table row and picture line afterwards.

Nothing was built or run for the manuals' sake. A sentence was accepted when the code or the bundled data bears it out for that manual's platform; "read in code, not seen running" is the standing caveat, and the sections below say where it matters most.

Since #1578 the manuals describe the reader as `v2` draws it (person and cross-reference links underlined at rest), which is not what build 49 on TestFlight draws.
